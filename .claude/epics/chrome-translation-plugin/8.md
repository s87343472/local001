# Task: Popup Interface

## Description
Create the popup UI that appears when clicking the extension icon in the browser toolbar. Provides quick status display, translation controls, progress indicator, and shortcuts to settings and statistics.

## Acceptance Criteria
- [ ] Popup displays when clicking extension icon
- [ ] Current page translation status shown
- [ ] Quick translate button functional
- [ ] Toggle translation on/off working
- [ ] Progress indicator during translation
- [ ] Quick settings (engine, language) accessible
- [ ] Links to full Options page and statistics
- [ ] Compact design (<400px width)

## Technical Details
- **Popup Dimensions**:
  - Width: 320px
  - Height: Auto (max 600px)

- **Layout Structure**:
  ```
  ┌──────────────────────────────┐
  │  🌐 Chrome Smart Translator  │
  ├──────────────────────────────┤
  │  Current Page: github.com    │
  │  Status: ✓ Translated        │
  │                              │
  │  [  🌐  Translate Page  ]   │
  │  [  ⇄  Toggle Display   ]   │
  │                              │
  │  Quick Settings:             │
  │  Engine: [Gemini ▾]         │
  │  Language: [简体中文 ▾]      │
  │                              │
  │  ─────────────────────────   │
  │  📊 This month: 45,678 chars│
  │  [⚙️ Settings] [📈 Stats]   │
  └──────────────────────────────┘
  ```

- **States to Display**:
  - Not translated: Show "Translate Page" button
  - Translating: Show progress bar + percentage
  - Translated: Show "Toggle Display" and "Retranslate" buttons
  - Error: Show error message + retry button
  - Blacklisted site: Show "Translation disabled on this site"

- **Quick Settings**:
  - Engine dropdown: Switch between Gemini/Google Translate
  - Language dropdown: Change target language
  - Changes apply immediately to next translation

- **Progress Indicator**:
  - Linear progress bar
  - Percentage text: "Translating 45%"
  - Estimated time: "~15 seconds remaining"

- **Communication**:
  - Query active tab for current translation state
  - Send messages to content script for actions
  - Update display based on responses
