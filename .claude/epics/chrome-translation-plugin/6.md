# Task: Content Detection Engine

## Description
Implement the content detection algorithm that identifies main content areas on web pages, extracts paragraphs for translation, and filters out non-content elements (navigation, ads, code blocks, etc.). Integrate with local cache for duplicate detection.

## Acceptance Criteria
- [ ] Content detection algorithm implemented with priority-based strategy
- [ ] Paragraph extraction working for various page structures
- [ ] Filter rules successfully exclude non-content elements
- [ ] Semantic HTML5 tags properly recognized (<article>, <main>)
- [ ] Paragraph density algorithm implemented as fallback
- [ ] Code blocks (<code>, <pre>) correctly excluded
- [ ] Translation cache integration for duplicate detection
- [ ] Tested on 10+ diverse websites

## Technical Details
- **Detection Priority Strategy**:
  1. HTML5 semantic: <article>, <main>, [role="main"]
  2. Common selectors: #content, .content, .post, .article
  3. Density algorithm: text_chars / (tags + links)

- **Filter Rules**:
  - Exclude: <nav>, <aside>, <footer>, <button>, <input>, <code>, <pre>
  - Exclude by class/id: *ad*, *sidebar*, *navigation*
  - Exclude: [aria-hidden="true"]

- **Paragraph Extraction**:
  - Minimum length: 20 characters
  - Merge short consecutive paragraphs (<50 chars)
  - Split long paragraphs (>5000 chars)
  - Preserve paragraph grouping for context

- **Cache Integration**:
  - Hash paragraphs for cache lookup
  - Use SHA-256 for consistent hashing
  - Return cached translations when available
