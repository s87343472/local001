# Task: Floating Button UI

## Description
Create the floating action button on web pages with state management (idle, translating, translated, error), expandable panel for quick controls, progress indicator, and responsive positioning that doesn't obstruct page content.

## Acceptance Criteria
- [ ] Floating button displays on right side of pages
- [ ] Button states implemented (idle, translating, translated, error)
- [ ] Click triggers translation workflow
- [ ] Expandable panel shows status and controls
- [ ] Progress indicator displays during translation
- [ ] Responsive positioning (desktop, tablet, mobile)
- [ ] Button doesn't obstruct important page content
- [ ] Smooth animations and transitions

## Technical Details
- **Button Design**:
  - Size: 60×60px (desktop), 48×48px (mobile)
  - Position: Fixed, right: 20px, top: 50%
  - z-index: 999999 (highest layer)
  - Border-radius: 50% (circular) or 8px (rounded square)
  - Shadow: rgba(0,0,0,0.2) 0px 2px 8px

- **States**:
  1. Idle: Blue (#4A90E2), translate icon
  2. Translating: Orange (#F0AD4E), spinner animation, progress %
  3. Translated: Green (#5CB85C), checkmark icon
  4. Error: Red (#D9534F), warning icon

- **Expanded Panel** (280px × auto):
  ```
  ┌─────────────────────────┐
  │ 🌐 Smart Translator     │
  ├─────────────────────────┤
  │ Status: Translated ✓    │
  │                         │
  │ [⇄ Toggle Original]     │
  │ [🔄 Retranslate]        │
  │                         │
  │ Engine: Gemini          │
  │ Language: zh-CN         │
  │                         │
  │ [⚙️ Settings] [📊 Stats]│
  └─────────────────────────┘
  ```

- **Interactions**:
  - Click button: Trigger translation or toggle
  - Hover: Highlight/scale (1.05x)
  - Panel opens: Slide from right (200ms)
  - Click outside: Close panel

- **Progress Display**:
  - Circular progress ring around button
  - Percentage text inside button
  - Estimated time remaining (optional)
