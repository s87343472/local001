# Task: Translation API Integration

## Description
Implement Gemini API integration with domain-specific prompt engineering and Google Translate API as fallback. Include batch translation logic, error handling, retry mechanisms, and output validation.

## Acceptance Criteria
- [ ] Gemini API client implemented with proper authentication
- [ ] Domain-specific prompt templates created (computer science default)
- [ ] Batch translation logic working (max 10 paragraphs, 5000 chars)
- [ ] Google Translate API fallback operational
- [ ] Retry logic with exponential backoff (max 3 retries)
- [ ] Output validation and error recovery
- [ ] Rate limiting (max 3 concurrent requests)
- [ ] Translation quality checks implemented

## Technical Details
- **Gemini API Configuration**:
  - Endpoint: `https://generativelanguage.googleapis.com/v1beta/models/gemini-2.5-flash:generateContent`
  - Model: gemini-2.5-flash
  - Temperature: 0.3 (deterministic)
  - Max tokens: 2048

- **Prompt Template**:
  ```
  You are a professional {domain} translator.
  Task: Translate {source} to {target}.

  Requirements:
  1. Accurate technical terminology for {domain}
  2. Maintain tone and style
  3. Context-aware disambiguation
  4. Output: Pure JSON array format

  Technical terms ({domain}):
  {domain_dictionary}

  Input: {paragraphs}
  Output format: ["translation1", "translation2", ...]
  ```

- **Error Handling**:
  - API errors: Retry with backoff (1s, 2s, 4s)
  - Format errors: Attempt JSON extraction, then fallback
  - Timeout: 30s per request
  - Fallback to Google Translate on repeated failures

- **Quality Checks**:
  - Verify output is JSON array
  - Check translation length (not too short/long)
  - Detect untranslated text (same as input)
