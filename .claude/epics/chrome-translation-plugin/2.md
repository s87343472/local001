# Task: Bilingual Rendering Engine

## Description
Implement the bilingual parallel display system that inserts translations below original paragraphs without replacing them. Includes progressive rendering, show/hide toggle, MutationObserver for dynamic content, and cache storage of rendered translations.

## Acceptance Criteria
- [ ] Translations inserted below original paragraphs with proper styling
- [ ] Progressive rendering working (viewport first, <2s)
- [ ] Show/hide toggle functionality operational
- [ ] MutationObserver detects and translates dynamic content
- [ ] Original page layout preserved (no breakage)
- [ ] Translation styling distinguishable from original
- [ ] DocumentFragment used for batch DOM insertion
- [ ] Rendered translations cached locally

## Technical Details
- **DOM Structure**:
  ```html
  <p class="original" data-translated="true">Original text</p>
  <p class="translation" data-translation-id="hash"
     style="color: #666; font-style: italic; margin-top: 4px;">
    译文内容
  </p>
  ```

- **Progressive Rendering Strategy**:
  1. Extract all paragraphs
  2. Identify viewport-visible paragraphs (Intersection Observer)
  3. Translate visible first (target: <2s)
  4. Queue remaining for background translation
  5. Render as batches complete (5 paragraphs per batch)

- **Styling**:
  - Inject CSS with unique class names to avoid conflicts
  - Default: gray color (#666), italic, slightly smaller font
  - User-customizable via settings

- **MutationObserver**:
  - Watch for new nodes added to main content area
  - Debounce (300ms) to avoid excessive triggers
  - Auto-translate new content if translation is active
  - Avoid re-translating existing translated content

- **Toggle Mechanism**:
  - Hide: Set `.translation { display: none; }`
  - Show: Remove display property
  - Preserve translations in DOM (no re-translation)
