# Task: Security & Privacy Implementation

## Description
Implement comprehensive security measures including API key encryption enhancement, XSS prevention in translation rendering, CSP compatibility checks, blacklist enforcement for sensitive sites, and privacy policy documentation.

## Acceptance Criteria
- [ ] API key encryption verified secure (AES-256-GCM)
- [ ] API keys never exposed to content scripts or page context
- [ ] XSS prevention: translations use textContent, not innerHTML
- [ ] CSP compatibility: graceful degradation on strict CSP sites
- [ ] Blacklist enforcement: no injection on blacklisted domains
- [ ] Built-in blacklist includes banking/payment sites
- [ ] Privacy policy document created
- [ ] No data sent to non-API servers

## Technical Details
- **API Key Security**:
  - Encryption: AES-256-GCM with Web Crypto API
  - Key derivation: PBKDF2 with device fingerprint
  - Storage: Encrypted in chrome.storage.sync
  - Access: Only in background service worker
  - Never transmitted except to legitimate API endpoints

- **XSS Prevention**:
  ```javascript
  // CORRECT: Use textContent
  translationElement.textContent = translatedText;

  // WRONG: Never use innerHTML with API responses
  // translationElement.innerHTML = translatedText; // NO!
  ```
  - Sanitize any user input before storage
  - Escape special characters if needed
  - Validate API responses before rendering

- **CSP Compatibility**:
  - Detect page CSP using meta tag or headers
  - Test injection capability before proceeding
  - If CSP blocks: Show warning, don't break page
  - Use inline styles with style attribute (more permissive)

- **Blacklist Enforcement**:
  ```javascript
  const BUILTIN_BLACKLIST = [
    /.*\.chase\.com$/,
    /.*\.bankofamerica\.com$/,
    /.*\.paypal\.com$/,
    /.*\.stripe\.com$/,
    /accounts\.google\.com$/,
    // ... more patterns
  ];

  function isBlacklisted(url) {
    const hostname = new URL(url).hostname;
    return BUILTIN_BLACKLIST.some(pattern => pattern.test(hostname)) ||
           userBlacklist.some(domain => hostname.includes(domain));
  }
  ```
  - Check on content script injection
  - If blacklisted: Don't inject, log reason
  - User can override (with warning)

- **Privacy Measures**:
  - No analytics or tracking code
  - No data collection beyond local storage
  - API calls only: Gemini/Google Translate
  - Clear privacy policy explaining:
    - What data is stored locally
    - What data is sent to APIs (only translation text)
    - How API keys are protected
    - No third-party data sharing

- **Permissions Justification** (for Chrome Web Store):
  - `storage`: Save settings and cache locally
  - `activeTab`: Access current page content for translation
  - `scripting`: Inject content script for rendering
  - `https://*/*`: Required for API calls and content access
