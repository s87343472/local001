# Task: Settings & Configuration Page

## Description
Build the Options page for comprehensive settings management including API key configuration and validation, translation preferences, display customization, blacklist management, and usage statistics display.

## Acceptance Criteria
- [ ] Options page accessible via extension icon → Options
- [ ] API key input and validation working
- [ ] Translation preferences (engine, language, domain, mode) configurable
- [ ] Display settings (color, style, font size) with live preview
- [ ] Blacklist management (add/remove domains)
- [ ] Usage statistics displayed (chars translated, API usage)
- [ ] Settings persist across sessions
- [ ] Input validation and error messages

## Technical Details
- **Page Structure**:
  - Sidebar navigation: Basic, API Config, Preferences, Display, Blacklist, About
  - Main content area with forms
  - Save button with confirmation

- **API Key Configuration**:
  ```
  Gemini API Key: [________________] [Validate]
  Status: ✓ Valid | ✗ Invalid | ⚠️ Not configured

  [Get your free API key] (link to Google AI Studio)

  Google Translate API Key (optional): [________________]
  ```
  - Validation: Test API call on button click
  - Show quota/usage if available
  - Encrypt before saving to storage

- **Translation Preferences**:
  - Target Language: Dropdown (zh-CN, ja, ko, es, etc.)
  - Default Engine: Radio (Gemini, Google Translate)
  - Professional Domain: Dropdown (Computer Science, General, etc.)
  - Translation Mode: Radio (Fast, Smart, Precise)
  - Auto-translate: Toggle

- **Display Settings**:
  - Translation Color: Color picker (#666666 default)
  - Font Style: Dropdown (normal, italic)
  - Font Size: Slider (80%-120%)
  - Live Preview: Sample paragraph showing effect

- **Blacklist Management**:
  - Current blacklist: Chip list with delete buttons
  - Add domain: Input + Add button
  - Preset: Checkbox to include banking/payment sites
  - Import/Export: JSON download/upload

- **Statistics**:
  - Total characters translated: 1,234,567
  - Total requests: 456
  - This month usage: 123,456 chars
  - Cache hit rate: 32%
  - Simple bar charts (optional)
