# Extension Icons

For testing, you can temporarily use any PNG images (16x16, 32x32, 48x48, 128x128) or remove the icon references from manifest.json.

To generate proper icons:
1. Open create-icons.html in a browser
2. Save the 4 generated PNG files to this directory
3. Name them: icon-16.png, icon-32.png, icon-48.png, icon-128.png

Or use an online tool like https://redketchup.io/icon-editor
